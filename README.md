 MindMetrics 

**MindMetrics** is a simple mental wellness website created to encourage users to reflect on their mental well-being and learn more about maintaining a healthy mind.

The project focuses on creating a clean, welcoming, and easy-to-navigate experience using basic web technologies.

 Features

*  Mental wellness awareness and information
*  Simple and user-friendly interface
*  Responsive webpage design
*  Clean and calming visual design
* 🔗Easy navigation between sections

 Technologies Used

* HTML5
* CSS3

 Project Purpose

This project was created as a beginner web development project to practice **HTML and CSS** while building a website around the topic of mental wellness.
